Apply LUT Color Profiles to Your Overlay Videos

If you shoot in a log profile — GoPro D-Log M, DJI D-Log, or any other flat color science — you need a LUT to restore contrast and color before your overlay looks right. VeloOverlay now applies .cube LUT files directly in the FFmpeg encode pass, so grading and overlay rendering happen in a single step.

Setting up your LUT library

Desktop app

  1. Open Settings → Paths.
  2. Find the LUT Library Folder field and point it to the directory where you keep your .cube files.
  3. Save. The app scans the folder immediately and lists every .cube file it finds.

If you do not set a folder, the app looks in <userData>/luts/ by default — you can drop files there without opening Settings.

Web mode

Set the TELEMETRY_LUTS_DIR environment variable in apps/web/.env.local:

TELEMETRY_LUTS_DIR=/path/to/your/luts

If the variable is not set, public/luts/ inside the app folder is used.

Selecting a LUT before rendering

  1. Open the Render page.
  2. Expand the Video Effects panel.
  3. Choose a file from the LUT File dropdown — only files in your configured library appear here.
  4. Start the render as usual.

The LUT is applied after all Video Tuning corrections (brightness, contrast, saturation, gamma) and before the final encode. You get one fully graded, overlay-composite file out the other side.

Tips

  • Log footage only: LUTs designed for D-Log or V-Log footage will produce blown-out or washed-out results on standard color profiles. Always match the LUT to your camera’s color science.
  • Preview isn’t affected: The editor canvas always shows un-graded footage. Check your grade by rendering a short test clip first.
  • Removing a LUT: Select None from the dropdown to render without a LUT.
  • Free LUT sources: Many camera manufacturers publish official creative LUTs for their log profiles on their support sites.
